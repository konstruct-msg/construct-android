# crypto/

UniFFI wrapper around `construct-core` (Rust).

- `ClassicCryptoCore.kt` — generated UniFFI bindings. **Do not edit by hand** (regenerated by `build_crypto_lib.sh`).
- `CryptoManager.kt` — singleton wrapper. All crypto goes through here; UI must not call bindings directly.
